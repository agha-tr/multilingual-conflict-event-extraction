## v0.2.0-public-methods — 2026-08-23

### Added

- synchronized public packages for GitHub and the editable OSF Project;
- current project status, public collection-design summary, ethics policy, preregistration status, and release boundary;
- pilot codebook v0.2, extraction prompt v0.2, lean model-output schema v0.1, and run-record schema v0.1;
- deterministic prompt, output, run-record, and structural-evaluation utilities;
- synthetic contract tests and GitHub Actions configuration;
- dual licensing, citation template, contribution rules, and sensitive-data reporting guidance.

### Clarified

- the benchmark has no news-only rule;
- public social media may be eligible after collection QA;
- the older mixed OSINT/HUMINT archive is not the benchmark sampling frame;
- faithfulness to one source is not real-world verification;
- Urdu and Pashto inclusion is a substantive design feature, not a predetermined deficit claim;
- live source registries, acquisition queries, candidate data, annotations, translations, model outputs, and results remain private at this stage.

### Status

- Research in progress; no main-study results.
- Formal preregistration pending post-pilot protocol freeze.
