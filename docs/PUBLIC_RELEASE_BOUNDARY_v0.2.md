# Public release boundary v0.2

## Public now

- project overview and current status;
- Paper 1 scope lock and public collection-design summary;
- pilot annotation codebook, extraction prompt, and JSON Schemas;
- public evaluation plan;
- deterministic validation and structural-evaluation utilities;
- synthetic tests and continuous-integration configuration;
- preregistration status, ethics policy, licenses, citation template, and changelog.

## Not public now

- the researcher's older archive or any material combining OSINT and HUMINT;
- raw source text, posts, screenshots, media, transcripts, or captured HTML;
- live source registries, exact acquisition queries, and target-selection logic;
- candidate locators, production manifests, retrieval responses, or source captures;
- annotation workbooks, adjudication records, translations, or gold labels;
- raw model outputs, provider request identifiers, billing records, or execution logs;
- API keys, environment files, credentials, headers, or account details;
- the working manuscript, unreviewed tables, and preliminary results;
- annotator identities, contracts, contact information, or private project logs.

## Later release review

Method files may be promoted from pilot to v1.0 at preregistration. Aggregate results and sanitized examples may be added after analysis. Item-level materials require a separate legal, ethical, privacy, platform, and dual-use decision. Public-source status alone does not create permission to redistribute.

## No hidden data dependency

The synthetic code tests in this release do not require the withheld corpus. They verify software contracts only. Full empirical replication will depend on the final tiered data-access decision, which will be reported without implying access that is not actually available.
