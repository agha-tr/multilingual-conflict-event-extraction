# Security and sensitive-data reporting

Do not open a public issue containing source texts, private archive information, credentials, personal identifiers, precise operational details, or accidental sensitive-data exposure.

Use a private contact channel associated with the repository owner or OSF contributor profile. If the repository enables private vulnerability reporting, that channel may also be used for software issues. Include only the minimum information necessary to locate the problem.

This policy covers accidental disclosure and software security. It is not a channel for submitting intelligence, target information, or private source material.
