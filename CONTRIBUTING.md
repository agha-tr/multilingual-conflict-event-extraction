# Contributing

The repository currently accepts corrections to public documentation, schemas, deterministic utilities, and synthetic tests. It does not accept conflict-source submissions, source lists, personal data, screenshots, propaganda media, or live operational information through public issues or pull requests.

Before proposing a change:

1. avoid posting sensitive or identifying material;
2. state whether the change affects a frozen or pilot artifact;
3. add or update a synthetic test for code-contract changes; and
4. preserve version history rather than silently rewriting a published method.

Method changes made after preregistration will follow the documented deviation policy.
